# Write-up media package

This folder is the compact figure/video set for the project write-up. All generated
frames come from the local checkpoints listed in `manifest.json`; nothing was
retouched or generated by an external image model.

`source-video-grid/` contains sixteen four-second excerpts from sixteen distinct
original VPT videos for the website's 4×4 source-data grid.

The three held-out contexts are a grassland river, a desert village, and a flower
forest. Each has at least twenty clean recorded future transitions. The same scenes
are reused across V1 and V2 wherever their different context requirements permit.

## Main sequence

1. `01-source-data-grid.png` — synchronized public VPT source frames.
2. `02-flat-vs-spatial-reconstruction.png` — exact same frames through both encoders.
3. `03-v1-recursive-filmstrip.png` — real versus best-V1 recursive futures.
4. `04-v1-action-comparisons.png` — forward, left, right, and idle across all scenes.
5. `05-ablation-summary.png` — data, recursive-horizon, and capacity ablations.
6. `06-v2-recursive-filmstrip.png` — V2 failure under recorded actions.
7. `07-v2-action-comparisons.png` — V2 action response and generative drift.
8. `08-interactive-demo-v1.mp4` — scripted controls through the same V1 engine used
   by the browser demo. It resets between short control sequences across all three
   held-out scenes so control remains legible instead of hiding behind long-horizon blur.

Each composite PNG also has a same-named folder containing its individual source
frames or plot panels before the collage layout is applied.

The per-scene action-comparison PNGs are supplementary figures. V1 here is the best
completed capacity checkpoint (1.84M dynamics parameters, ten-step recursive
fine-tuning), not the older CLI default. V2 uses 32 deterministic DDIM steps and a
camera magnitude of 75; V1 uses the same camera magnitude for a fair visible-control
comparison.
